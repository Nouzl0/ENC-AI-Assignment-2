# Verze 2 referencí doplňkových otázek

AI ověření po sběru, bez nezávislého lidského schválení. Původní otázky, ID, jazyky a prompty jsou byte shodné; původní verze zůstává uchovaná. Opravy RF/RC a čtyř schema enumů jsou popsány v CORRECTION_AUDIT.md a použity jednotně pro všechny podmínky. Všech 18 RF má datované ověření na otevřeném oficiálním zdroji. Nejde o zdrojovou podporu konkrétních citací modelů ani o zpětné splnění G1/G2/G3.

Tyto otázky už jsou zveřejněné a použité. Nejsou neviděný holdout pro další ladění. Soukromé zdrojové snapshoty zůstávají u správce; public manifest obsahuje hash, identifikátor, URL a locator. Hodnotitel musí gold nezávisle zkontrolovat.
