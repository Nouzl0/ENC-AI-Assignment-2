(glossary)=
# Příloha B: pojmy a zkratky

| Pojem | Význam |
| --- | --- |
| **Produkt** | Model + vyhledávání + rozhraní jako celek (např. webové ChatGPT) |
| **Tvrzení** | Atomický faktický výrok v odpovědi |
| **Dvojice** | Tvrzení a zdroj, který k němu produkt skutečně připojil |
| **S2 / S1 / S0** | Zdroj tvrzení plně / částečně / nepodporuje |
| **NA** | Zdroj se nepodařilo přečíst; **FAB** – zdroj neexistuje |
| **RF / OF / RC** | Povinná fakta / nepovinná fakta / požadavky na formát a zdroje v referenci úlohy |
| **P1 / P2 / P3** | Společný výchozí / strukturovaný / optimalizovaný prompt |
| **Dev / val / test** | Vývojová, validační a soukromá testovací sada |
| **G1 / G2 / G3** | Brány: zmrazení protokolu / promptu P3 / konec hodnocení |
| **Citační přesnost** | Podíl S2 mezi všemi explicitními dvojicemi odpovědi (hlavní metrika) |
| **CI** | Interval spolehlivosti (párový bootstrap po úlohách) |
| **κ** | Cohenova kappa, shoda dvou hodnotitelů mimo náhodu |
| **unknown** | Hodnota, kterou rozhraní nezobrazilo; nikdy se nenahrazuje odhadem |
